### 2026-10-03 - Collapsible workspace explorer and drawer

- What changed: replaced the right description panel with a left explorer. A visible header toggle and Cmd/Ctrl+B switch between the explorer and compact desktop activity bar. Build, Operate and Recent sessions collapse independently. Filtering reveals matching views and session names/IDs; view links resume the shell's remembered record. Desktop open/closed state and collapsed groups persist without storing session data.
- Narrow screens: at 960 px and below the same explorer is a full-height left drawer using the existing Dialog focus controller. It closes on Escape, backdrop, close or navigation, and restores focus. Mobile opening does not overwrite the desktop preference.
- Evidence: `npm run check` (zero errors/warnings), scoped ESLint and Stylelint, production build, full Vitest suite (1,199 passed, three existing API-dependent skips), and five E4 Playwright checks against the remote Docker API/Postgres fixture. The final shell focus refinement also passed all 21 IDEShell tests. Desktop/collapsed/drawer screenshots are in the E4-5 artifacts under `ui/e2e-results`.
- Scope: only resources with working links appear. Recent sessions reuse the existing Home read and show eight rows, with loading/empty/error/refresh and capability/build gating. That API does not support server pagination; the list is fetched on open or explicit refresh, without polling. Resource trees for profiles, definitions and connections remain a later slice once record selection is supported consistently.
- Review: the replacement deletes the old context-copy module and its tests. The combined UX MR exceeds 500 changed lines because it replaces that panel and covers shell, persistence, responsive dialog behavior and real-browser regressions. No dependencies or security gates changed. The preceding MR pipeline is blocked by existing npm audit findings (including braces, for which the advisory lists no patch); new pipeline evidence is tracked on MR !271.
- Sources: `ui/src/lib/ui/ide/sidebar/Explorer.svelte`, `ui/src/lib/ui/ide/IDEShell.svelte`, `ui/e2e/shell.spec.ts`, MR !271.
