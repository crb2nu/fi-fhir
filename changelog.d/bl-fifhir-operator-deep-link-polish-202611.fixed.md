- Operator deep links (`?receipt=`, `?attempt=`, `?definition=&revision=`) now wait for the capability pre-flight before they apply. A link opened in a fresh bearer tab is held until the `/api/auth/status` probe answers (new `accessProbePending` in `ui/src/lib/graphql/accessCapabilities.ts`). It is then applied once, or it gives way to the forbidden / not-configured pre-flight; it no longer selects a record the page cannot show. An older server that stays `unknown` still applies the link once its probe has answered (`OperatorPage.svelte`). The attempt inspector now links a resubmitted attempt's children ("Resubmitted as") as well as its parent. The attempt type exposes only `parentAttemptId`, so the inspector reads the children from the receipt's trace (`AttemptInspector.svelte`, `resubmitChain.childAttempts`).
