- Build: the image build (`Dockerfile`, `build:docker`) retries `go mod download` up to three times with a 5 s then 10 s backoff instead of failing the whole build on one transient proxy.golang.org HTTP/2 stream reset (`stream error: stream ID N; INTERNAL_ERROR; received from peer`), which cost two Mills merge trains and one merge-request pipeline on 2026-11-03. Modules that finished before the reset stay in the module cache, so a retry only fetches what was cut off; the trace prints the attempt counter so the retry path is visible when it fires.
