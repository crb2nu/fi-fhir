- IDE shell accessibility nits from the E-4 review. `Dialog.svelte` moves focus to its own surface when nothing inside can take it. It also swallows an Escape pressed before focus has entered, so a keypress during the open transition no longer closes the dialog or reaches the page. The close buttons in `Tabs.svelte` are aria-hidden pointer affordances, so the tablist exposes only tabs; closable tabs advertise Delete through `aria-keyshortcuts`. A new `TabItem.description` sets `aria-description`. In `BottomPanel.svelte`, a dimmed Copilot tab gives the reason in its `title` and `aria-description`: "No LLM is configured for this deployment", or the LLM capability warning when the provider is unavailable.
