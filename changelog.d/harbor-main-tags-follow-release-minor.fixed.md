- Main-branch images are tagged `v<released major.minor>.<pipeline id>` on Harbor (`v0.2.38400`) instead of a fixed `v0.1.<pipeline id>`, read from the newest `## [x.y.z]` heading in `CHANGELOG.md`. Release tags now land in the same repository and the same Flux semver range, and a `v0.2.2` above every `v0.1.N` would have pinned the cluster to that release until the next one; with the minor tracked, the next main build outranks it again.
