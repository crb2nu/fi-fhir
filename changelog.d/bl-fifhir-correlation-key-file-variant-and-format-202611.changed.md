- `fi-fhir serve` reads the telemetry correlation key from `FI_FHIR_TELEMETRY_CORRELATION_KEY` or `FI_FHIR_TELEMETRY_CORRELATION_KEY_FILE` (exactly one, through the shared serve secret loader) and now requires it to be the hex or base64 (standard or URL alphabet, padded or not) encoding of at least 32 random bytes. A raw 32-character passphrase is refused at startup with an error that names the format and never echoes the value (`cmd/fi-fhir/serve_tracing.go`, `cmd/fi-fhir/engine_runtime.go`, `cmd/fi-fhir/main.go`, `.env.example`).
