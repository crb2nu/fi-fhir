- CI job `lint:edi-fixtures` (`ci/lint-edi-fixtures.yml`, wired from `.gitlab-ci.yml` and `ci/job-inventory.txt`) runs edilint pinned to `v0.1.0` over `testdata/edi/*.edi` against the committed `testdata/edi/.edilint.yml` on every merge request, and publishes `edilint-report.xml` as a JUnit report so X12 envelope defects show up in the MR test panel. It is added beside the existing `lint:edi` job, which is left exactly as it was and still checks the same corpus on edilint's stock rules with no config file. `testdata/edi/.edilint.yml` waives EL3009 (duplicate interchange control number), because the fixtures are independent interchanges and control-number uniqueness across the corpus is not an invariant the suite maintains. `internal/parser/edi/fixtures_test.go` pins every fixture's SE01 against the segments it actually contains, so `go test ./internal/parser/edi/...` catches a miscounted trailer without needing the network; the three miscounts edilint originally found were repaired on `main` in `df45f683`, and this is the first thing that keeps them repaired.
